# Amardeep School Bus Tracking

This repository is the Supabase-powered version of the Amardeep Public Senior Secondary School bus tracker.

**Setup guide:** Read `README-SUPABASE.md` from top to bottom.
**Database security and setup SQL:** `supabase-setup.sql`

Do not publish until you have configured the Supabase project URL/key, school coordinates, user accounts and profiles.
